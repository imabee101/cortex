# Cortex 1.0.45

- First Cortex release: the agent harness now talks to one server, `https://llm.imabee.com`, and runs on a local llama.cpp model.
- Sign in with the browser or the device flow; accounts live on the server.
- Web search runs on the server; image generation, video generation and voice dictation are off.
- `cortex update` and the install script are served by the same host.
