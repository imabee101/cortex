# @cortex-official/cortex-linux-x64

Platform-specific binary for [`@cortex-official/cortex`](https://www.npmjs.com/package/@cortex-official/cortex) on linux-x64.

Do not install this package directly. Install the main package instead:

```sh
npm install -g @cortex-official/cortex
```

The main package will automatically pull the correct binary for your platform via `optionalDependencies`.
